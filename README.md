# Win7 Retro — Windows 11 → Windows 7

Программа-гид для превращения Windows 11 в стиль **Windows 7 (Aero)**.
Применяет настройки и системные ассеты, ведёт по шагам установку сторонних
инструментов (OpenShell, StartAllBack, патчер uxtheme) и умеет откатывать изменения.

---

## Содержимое проекта

| Файл / папка | Что это |
|---|---|
| `dist\Win7Retro.exe` | Готовое приложение (собрано PyInstaller, работает без Python) |
| `win7_retro.py` | Исходный код приложения (tkinter GUI) |
| `gen_assets.py` | Скрипт генерации собственных ассетов в стиле Aero |
| `build_gallery.py` | Скрипт сборки HTML-галереи иконок |
| `win7-aero-wallpaper.jpg` | Обои в стиле Aero (синий градиент + глянец) |
| `win7_icons\` | **2195 оригинальных иконок Windows 7** (.ico) + системные звуки |
| `win7_icons\preview\` | PNG-превью всех иконок для галереи |
| `win7_icons_gallery.html` | Галерея выбора иконок (открыть в браузере, клик = копия пути) |
| `win7_icons_pack.zip` | Скачанный архив с иконками и звуками |
| `build\`, `Win7Retro.spec` | Служебные файлы сборки PyInstaller |

## Установка и запуск

### Способ 1 — готовый `.exe` (рекомендуется)
1. Запусти `dist\Win7Retro.exe`.
2. Для операций, требующих прав, запусти **от имени администратора**
   (ПКМ → «Запуск от имени администратора»).

### Способ 2 — из исходника
1. Установи Python 3 (с галкой **Add to PATH**).
2. Запусти: `python win7_retro.py`

## Как пользоваться — по вкладкам

| Вкладка | Что делает |
|---|---|
| **1. Проверка** | Авто-диагностика: версия Windows, права, наличие инструментов, статус патча uxtheme |
| **2. Меню Пуск** | Находит/запускает OpenShell и StartAllBack; авто-скачивание актуального OpenShell с GitHub |
| **3. Тема Aero** | Установка сторонних тем `*.theme` / `*.msstyles` в стиле Win7 + патч uxtheme |
| **4. Обои** | Безопасное применение обоев (можно выбрать `win7-aero-wallpaper.jpg`) |
| **5. Курсоры** | Установка схемы курсоров Aero из папки с `.cur` / `.ani` |
| **6. Звуки** | Прописывание `.wav` в системные события (папка `win7_icons\sounds\`) |
| **7. Иконки** | Смена значков Компьютер / Корзина / Сеть (иконки из `win7_icons\icon\`) |
| **Откат** | Бэкап реестра в `.reg` + создание точки восстановления |

## Подготовка ассетов (важно)

### Иконки рабочего стола — выбор через галерею
1. Открой `win7_icons_gallery.html` в браузере.
2. Найди визуально нужные: **Компьютер**, **Корзина (полная)**, **Корзина (пустая)**, **Сеть**.
3. Клик по иконке копирует путь к `.ico` в буфер.
4. Во вкладке **7. Иконки** вставь путь и нажми «Применить значки».

### Звуки
В папке `win7_icons\sounds\` лежат системные звуки Windows 7 (`.wav`).
Укажи её во вкладке **6. Звуки**.

### Обои
Свои — выбери `win7-aero-wallpaper.jpg` во вкладке **4. Обои**.
Оригинальный Bliss можно скачать отдельно (см. раздел *Источники*).

## Источники ассетов

- **Иконки и звуки Windows 7** — скачаны из открытого GitHub-репозитория
  `Korvenixx/IcoWinSevenPack1.0` (архив `win7_icons_pack.zip`).
- **OpenShell** (классическое меню) — `https://github.com/Open-Shell/Open-Shell-Menu/releases`
  (скачивается прямо из приложения).
- **StartAllBack** (точный вид панели задач Win7) — `https://www.startallback.com/`
- **Патчер uxtheme** (для сторонних тем) — `https://mhoefs.eu/software_uxtheme.php`
- **Обои Bliss** — `https://archive.org/download/windows-bliss-wallpaper-pack`

## Важно: авторские права и риски

- **Оригинальные иконки, звуки и обои Microsoft** можно использовать
  **на своей машине для личного применения**. Но их **нельзя** включать в
  собственный дистрибутив приложения или распространять как часть продукта —
  это собственность Microsoft.
- Поэтому **репозиторий не содержит точной Aero-темы Windows 7
  (`aero.msstyles`) и фирменной орбиты-логотипа** — они вводятся пользователем
  вручную отдельными файлами.
- **Патч uxtheme.dll** и сторонние темы **слетают после крупных обновлений
  Windows** — потребуется повторный запуск патчера.
- Все операции с темами, курсорами, звуками и системными значками — **на ваш
  риск**. Перед серьёзными изменениями сделайте бэкап во вкладке **Откат**.

## Сборка `.exe` заново

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name Win7Retro win7_retro.py
```

Результат — `dist\Win7Retro.exe`.

## Технологии

- Python 3.14 + tkinter (GUI)
- PyInstaller (упаковка в `.exe`) — версия 6.22
- Pillow (генерация ассетов)
- GitHub API (авто-скачивание OpenShell)
- Работа с реестром Windows через `reg` / `ctypes`
